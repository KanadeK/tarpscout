# TarpScout

TarpScout is an offline solver for finding A-frame and lean-to tarp pitches that
fit a measured campsite, required covered footprints, stakeable ground, circular
keep-outs, and the reusable cord segments you actually have.

The v0.1.0 implementation is in progress. The authoritative behavior contract is
in [docs/spec.md](docs/spec.md).

TarpScout produces planning evidence, not structural or weather-safety approval.
Always inspect the site and follow the tarp, cord, pole, stake, and land manager
instructions.
