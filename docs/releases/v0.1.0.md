# TarpScout v0.1.0

The first public release turns measured campsite constraints into inspectable
A-frame and lean-to tarp plans. It is a real offline solver, not a visual mockup.

## Highlights

- actual support span and attachment-height search;
- required footprint coverage inside projected tarp geometry;
- stake placement inside measured polygons;
- tarp/stake/guyline avoidance of circular keep-outs;
- exact one-to-one assignment of reusable cord segments;
- deterministic ranking, rejection counts, and repair hints;
- JSON, CSV, labelled SVG, and self-contained no-script HTML;
- four built-in demos covering two feasible and two blocked outcomes.

## Install

```powershell
python -m pip install https://github.com/KanadeK/tarpscout/releases/download/v0.1.0/tarpscout-0.1.0-py3-none-any.whl
tarpscout demo demo-output
```

## Limits

Results are planning evidence for a local level-plane model. They do not certify
wind/snow loads, fabric, sag, soil, trees, poles, knots, stakes, or any physical
anchor. `no_solution` is limited to the supplied constraints and finite grid.
